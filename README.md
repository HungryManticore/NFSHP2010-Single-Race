My Single Race mod, originally written for NFS Hot Pursuit Remastered, ported to NFS Hot Pursuit (2010). Tested on the DRM-free version of the .exe.

Click [here](https://github.com/HungryManticore/NFSHPR-Single-Race) for details.

# Known issues
Does not work with NFSHP2010: Frame Rate Unlocker by XeroAbsolute - game crashes to desktop when a race is started.
